# Docs Structure

Use one folder per assignment:

```text
docs/
├── assignment-1/
├── assignment-2/
└── assignment-N/
```

Suggested contents for each assignment folder:

- `instructions.*` for the original assignment brief
- `PLAN.md` for the working plan
- `screenshots/` for required submission screenshots
- `notes.md` only if needed

Keep the active API source at the repository root while each assignment continues the same project. Create separate source folders only when an assignment becomes a separate app.
